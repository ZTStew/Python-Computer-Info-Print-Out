# Computer Info Print Out
---
## Description:  
Program is designed to gather information relavent to the computer's hardware specs in order
to print them out

Intended to be run in addition to other programs


---
## Tasks:
- [ ] Hardware Information Required
  - [X] Platform (Windows/Linux/MacOS)
  - [-] CPU (i3/i5/i7/M1/M3/M5/ect.)
  - [-] Processor Generation (1st/4th/7th/10th)
  - [X] Core Count (2 Core/4 Core/8 Core)
  - [X] RAM (2GB/4GB/8GB/16GB)
  - [ ] Hard Drive Type (HHD/SSD)
  - [ ] Hard Drive Size (64GB/256GB/1TB)
  - [ ] Battery Health (10%/50%/100%)
  - [ ] Addons (Optical Drive/Camera/Touch Screen/ Num Pad)
  - [ ] Ports List (USB 2.0/USB 3.0/HDMI/VGA)
  - [ ] Age? (10 years/5 years/ 2 years)
